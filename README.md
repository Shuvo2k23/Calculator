# Calculator

A basic browser calculator built with vanilla HTML, CSS, and JavaScript.

## Features

- Addition, subtraction, multiplication, and division
- Decimal point support
- Clear (AC) and backspace (DEL)
- Percentage toggle
- Sign toggle
- Full keyboard support
- Divide-by-zero error handling

## Run

Option 1 - Locally:
1. Clone the repo: `git clone https://github.com/Shuvo2k23/Calculator.git`
2. Open `index.html` in your browser.

Option 2 - GitHub Pages:
1. Open the repo Settings, then Pages
2. Set source branch to `main` and save
3. Visit `https://shuvo2k23.github.io/Calculator/`

## Files
